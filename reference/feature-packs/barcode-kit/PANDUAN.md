# Archived barcode and attendance feature pack

This historical package contains Firebase-specific sample code and setup
instructions. It is not part of the active application. Do not install its
Firebase dependencies, run its Firebase CLI commands, or copy its Firebase
rules/configuration into this repository.

The active application implements student records and attendance with Supabase
services and migrations. Use those active modules and their tests instead.
This archive is retained only as source history; it does not establish feature
parity or authorization for the active Supabase implementation.
