## Temuan dasar dan batas verifikasi

- Rantai lama yang terbukti dari alur sumber: RPE → ATP → Prota → Prosem, dengan ATP → KKTP dan ATP/Prota/Prosem → Modul Ajar; Modul Siswa juga menggunakan metadata ATP/Prosem. Cover memakai identitas dokumen. Ini bukan jaminan semua cabang sinkron secara transaksional.
- Implementasi ATP baru menyajikan draf JSON lokal, editor metadata manual, validasi kontrak AI, serta renderer enam bagian; kesetaraan JP/UH, pratinjau/cetak, dan integrasi Apps Script tertaut belum diverifikasi.
- Beberapa item perencanaan di `web/src/menu.js` masih placeholder; halaman/mesin internal tidak otomatis membuktikan seluruh alur pengguna terhubung.
- Perilaku PDF lama terbukti dari helper, tetapi keberhasilan konfigurasi Advanced Drive Service dan hak akses Drive perlu verifikasi runtime.
- Konfigurasi produksi, pembagian berkas Google, masa retensi aktual, dan penggunaan provider AI tidak dapat disimpulkan hanya dari file kebijakan/kode.
